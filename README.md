## 📌 Project Overview

**GenAI News Digest Assistant** is a Generative AI-powered tool designed to provide users with summarized and searchable news digests. Developed as part of the **Google GenAI Intensive program**, this project integrates the power of LLMs, embeddings, and RAG (Retrieval-Augmented Generation) to deliver intelligent news summarization and query-based information retrieval.

---

## 🚀 Key Features

- 🔍 **News Scraping**: Automatically scrapes full-text news articles from recent headlines  
- ✂️ **Summarization**: Generates concise article summaries using **Hugging Face BART**  
- 🧠 **Vector Embeddings**: Converts summaries into high-dimensional vectors via **FAISS**  
- 🔁 **RAG Agent**: Answers user queries using embedded news data with Retrieval-Augmented Generation  
- 📓 **Kaggle Notebook**: Fully documented and executable  
  🔗 [View Notebook](https://www.kaggle.com/code/harshinchurkar/genai-news-digest-assistant)
